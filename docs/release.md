# 출시 절차

개발·핫픽스·검증·승인 범위의 정본은 [앱 저장소 지침](/Users/eee/dev/myinven/hi-inven/AGENTS.md)입니다. [앱 공통 개발·검증 지침](/Users/eee/dev/docs/apps.md)의 관련 절도 실제로 읽되 프로젝트별 검수·승인 조건을 유지합니다.
일반 작업공간·릴리스 흐름은 [공통 개발 절차](/Users/eee/dev/docs/release-cycle.md), 사이트 형식은 [프로덕트 사이트 지침](/Users/eee/dev/docs/product-site.md)을 참고하며 아래 프로젝트별 공개·게시 승인 조건을 우선합니다.
App Store 승인과 실제 공개를 확인한 뒤 아래 순서를 지킵니다.
그 전에는 앱 변경을 작업/후보 브랜치에 두고 `main`에 머지하지 않습니다.
심사 중 수정·거절 대응·승인 후 실제 공개 대기도 같은 원칙을 따릅니다. 앱은 심사 통과 후 자동 출시하며 사이트 게시물 검토가 앱 공개를 지연시키지 않습니다.

1. 공개된 앱 후보·핫픽스를 앱 저장소 `main`에 머지하고 앱 코드·프로젝트 설정이 실제 업로드 소스와 같은지 확인합니다. 문서 변경은 보존합니다. 앱 소스 충돌을 임의 수정해 다른 코드를 출시 코드로 마감하지 않으며, 먼저 선행 릴리스/핫픽스 관계를 확인합니다. 공개된 핫픽스는 영향을 받는 진행 중 작업/후보에도 전파·검증합니다.
2. 실제 업로드 빌드의 원본 소스 커밋에 annotated `vX.Y.Z` 태그를 만들고 push합니다. 당시 최신 `main`을 임의로 태그하거나 기존 태그를 이동하지 않습니다.
3. 같은 태그로 GitHub Release를 작성합니다.
4. 사이트 `_posts/`에 출시 기록을 작성합니다.
   - 릴리스 노트: `YYYY-MM-DD-vX-Y-Z.md`, `categories: release`, 기능 중심
   - 일반 출시의 블로그: `YYYY-MM-DD-<slug>.md`, `categories: blog`, 만든 이유와 제품 방향·사용자 가치 중심. 핫픽스는 릴리스 노트만 준비하며 별도 홍보 블로그를 만들지 않습니다.
   - 최종 원고/식별·목표 URL·공개 기능/버전/날짜·생성 HTML의 title/description/canonical/H1/내부·설치 링크와 기존 게시 권한을 [공통 절차의 목적과 담당](/Users/eee/dev/app-growth/playbooks/release-review.md#목적과-담당)에서 검증된 인계 기록으로 확인한 현행 출시 검토 담당에게 전달합니다. 기존 자료·검증을 재사용하고 필요한 원고 변경만 보완합니다.
5. 사이트 변경과 채널별 정책 범위를 검증하고 **출시 게시물 검토 승인**의 최종 원고/URL 일치 및 게시 승인 포함 회신 또는 사용자 직접 승인을 확인한 뒤 사이트 `main`에 반영합니다. 사용자가 출시 연계 블로그·릴리스 노트의 게시 승인권을 현재 출시 검토 담당에게 위임했으므로 해당 범위를 재확인하지 않습니다. 최종본 변경은 다시 검토받고 회신 부재·불일치·권한 부재면 게시하지 않습니다. 게시물 검토 승인을 앱 main/태그/GitHub Release 등 별도 원격 마감 권한으로 확대하지 않습니다.
6. GitHub Pages 배포 후 배포 커밋과 홈페이지, `/privacy/`, `/support/`, 발행한 글과 정책 JSON의 HTTPS 응답을 확인합니다. 최종 URL·실제 게시/확인 시각과 한계·반영 원고/버전·검증 결과를 출시 검토 담당에게 한 번 보고합니다. 성장 전략 담당에게 중간 보고를 자동 중계하지 않습니다.
7. App Store Connect의 마케팅, 지원, 개인정보처리방침 URL과 실제 iPhone의 앱 링크를 확인합니다.
8. 변경의 main·후속 후보 반영과 증거 보존이 끝나고 다른 작업이 사용하지 않는 브랜치/worktree만 정리합니다.

앱 출시는 App Store Connect 상태와 실제 App Store 공개로 확인합니다.
출시 기록 마감은 앱 저장소의 annotated tag·GitHub Release와 사이트 릴리스 글이
동일한 버전·소스를 가리키는지 함께 확인합니다.
