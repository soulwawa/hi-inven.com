시행일: 2026년 8월 30일

안녕재고(이하 “앱”)는 사용자의 개인정보를 수집하거나 추적하지 않습니다. 이 방침은 앱의 현재 데이터 처리 방식을 설명합니다.

1. 수집하는 개인정보

앱은 회원가입이나 로그인 기능을 제공하지 않으며, 이름·이메일·전화번호 같은 개인 식별 정보를 필수로 요구하거나 개발자의 서버로 수집하지 않습니다.

온보딩에서 이름 또는 별명을 선택적으로 입력할 수 있습니다. 이 값은 사용자의 기기에만 저장되며 개발자에게 전송되지 않습니다.

2. 기기에 저장되는 정보

사용자가 선택한 이름 또는 별명, 물건 이름, 수량, 기한, 보관 장소, 메모, 사용·폐기 기록과 앱 설정은 사용자의 기기에만 저장됩니다. 앱을 삭제하면 앱에 저장된 데이터도 함께 삭제됩니다.

3. 대화 처리

대화 입력은 지원되는 기기에서 Apple의 온디바이스 모델을 사용하거나 앱 내부 규칙으로 처리합니다. 사용자가 입력한 대화와 재고 정보는 개발자의 서버로 자동 전송되지 않습니다.

사용자가 설정에서 대화 오류 제보를 선택하면 최근 이해하지 못한 문장 한 건과 당시 앱 답변이 메일 초안에 표시됩니다. 사용자가 내용을 확인하고 직접 보낸 경우에만 문의 이메일로 전달되며, 전체 대화와 재고 정보는 자동으로 첨부되지 않습니다.

4. 알림과 실시간 현황

기한 알림은 사용자가 권한을 허용한 경우 기기에서 예약됩니다. 잠금 화면의 실시간 현황도 기기에서 시작하고 갱신하며, 원격 푸시 서버를 사용하지 않습니다.

5. 제3자 제공

앱은 사용자의 콘텐츠나 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

6. 분석, 광고와 추적

앱은 광고 SDK, 제3자 분석 도구 또는 사용자 추적 기술을 사용하지 않습니다.

7. 방침 변경

앱의 데이터 처리 방식이 달라지면 앱 업데이트 전에 이 페이지를 함께 갱신합니다.

8. 문의

개인정보 관련 문의는 {{ site.support_email }}으로 보내주세요. 사용자가 문의 또는 오류 제보 메일을 보내면 이메일 주소와 직접 전송한 내용은 문의 확인과 답변 목적으로만 사용합니다.

문의와 오류 제보 메일은 답변과 후속 확인에 필요한 기간 동안만 보관하며, 더 이상 필요하지 않으면 삭제합니다. 사용자는 같은 이메일 주소로 자신이 보낸 문의 내용의 삭제를 요청할 수 있습니다.

웹사이트 방문 분석 안내

웹 분석 안내 적용일: 2026년 10월 15일

이 항목은 앱과 별개로 hi-inven.com 웹사이트에만 적용합니다. 웹 분석을 허용하면 Google Analytics 4를 이용해 방문 세션, 열어 본 페이지, 유입 사이트와 App Store 링크 클릭을 측정합니다. 통계는 분석에 동의한 웹 방문 표본이며, App Store 링크 클릭은 앱 설치 완료를 뜻하지 않습니다.

허용하기 전이나 거부한 상태에서는 Google 분석 스크립트를 불러오지 않습니다. 거부해도 사이트와 설치 링크를 이용할 수 있으며, 페이지 하단의 ‘웹 분석 설정’에서 선택을 바꿀 수 있습니다. 선택은 이 브라우저에 저장됩니다. 허용을 철회하면 이후 측정을 중지하고 이 사이트의 분석 쿠키를 지웁니다. 이미 전송된 통계가 자동 삭제되는 것은 아닙니다.

허용한 경우 Google이 방문 구분용 쿠키, 브라우저·기기 정보와 방문 이벤트를 처리하며, 통신에 필요한 IP 주소도 Google에 전달됩니다. 페이지 주소의 쿼리·해시와 유입 주소의 경로·쿼리·해시는 분석 값에서 제외합니다. 앱의 재고·대화·사진, 문의 이메일 주소와 계정 정보를 분석에 보내지 않으며, 광고·리마케팅 용도로 사용하지 않습니다.

Google의 정보 처리는 Google의 파트너 사이트 데이터 이용 안내에서 확인할 수 있습니다. 웹 분석 관련 문의와 삭제 요청은 위 문의 이메일로 보내주세요.
