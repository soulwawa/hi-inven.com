--- layout: page title: 개인정보처리방침 description: 안녕재고가 사용자 데이터를 다루는 방식입니다. ---

시행일: 2026년 8월 14일

안녕재고(이하 “앱”)는 사용자의 개인정보를 수집하거나 추적하지 않습니다. 이 방침은 앱의 현재 데이터 처리 방식을 설명합니다.

1. 수집하는 개인정보

앱은 회원가입이나 로그인 기능을 제공하지 않으며, 이름·이메일·전화번호 같은 개인 식별 정보를 요구하거나 수집하지 않습니다.

2. 기기에 저장되는 정보

사용자가 입력한 물건 이름, 수량, 기한, 보관 장소, 메모, 사용·폐기 기록과 앱 설정은 사용자의 기기에만 저장됩니다. 앱을 삭제하면 앱에 저장된 데이터도 함께 삭제됩니다.

3. 대화 처리

대화 입력은 지원되는 기기에서 Apple의 온디바이스 모델을 사용하거나 앱 내부 규칙으로 처리합니다. 사용자가 입력한 대화와 재고 정보는 개발자의 서버로 전송되지 않습니다.

4. 알림과 실시간 현황

기한 알림은 사용자가 권한을 허용한 경우 기기에서 예약됩니다. 잠금 화면의 실시간 현황도 기기에서 시작하고 갱신하며, 원격 푸시 서버를 사용하지 않습니다.

5. 제3자 제공

앱은 사용자의 콘텐츠나 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

6. 분석, 광고와 추적

앱은 광고 SDK, 제3자 분석 도구 또는 사용자 추적 기술을 사용하지 않습니다.

7. 방침 변경

앱의 데이터 처리 방식이 달라지면 앱 업데이트 전에 이 페이지를 함께 갱신합니다.
